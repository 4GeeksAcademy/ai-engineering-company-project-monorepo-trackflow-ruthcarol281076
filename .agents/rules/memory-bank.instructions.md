# Regla del banco de memoria

Esta regla se aplica siempre a todos los archivos del repositorio.

Antes de modificar código o documentación:

1. Leer `CONTEXT.md`.
2. Leer `memory-bank/projectbrief.md`.
3. Leer `memory-bank/techContext.md`.
4. Leer `memory-bank/progress.md`.
5. Revisar el README de la carpeta afectada.

Después de cada cambio relevante, actualizar `memory-bank/progress.md`.

No modificar `memory-bank/techContext.md` si el cambio altera una decisión arquitectónica sin confirmación explícita del desarrollador.
